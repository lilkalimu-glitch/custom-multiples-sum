# Dynamic Multiples Sum

A flexible Python CLI tool that calculates the sum of all multiples for custom divisor values up to a user-defined upper limit.

This project is an extended, dynamic CLI implementation inspired by [Project Euler Problem 1](https://projecteuler.net/problem=1). Instead of restricting calculations to hardcoded limits and fixed target numbers (like 3 and 5 below 1000), this script lets users dynamically set their own upper boundary and divisor set via the command line.

## Features

- **Custom Upper Boundary:** Set any limit for the search space dynamically.
- **Dynamic Divisors:** Input any set of target divisors instead of hardcoded numbers.
- **Command-Line Utility:** Simple interactive prompt for fast user input.
